# Influencers World dashboard

Next.js App Router and React. Uses the supplied `../frontend-design.skill`, Syne and Plus Jakarta Sans typography, and Quill 2 for content descriptions.

## Setup

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

Open http://localhost:3000/login. Start the sibling `../InfulencersBackend` project, apply its migrations, and create the admin as described in its README. Sign in using the administrator credentials you supplied. Set the server-only `API_INTERNAL_URL` to the backend origin if it is not http://localhost:4000. The previous `NEXT_PUBLIC_API_URL` configuration is accepted as a fallback. Set `NEXT_PUBLIC_WEBSITE_URL` to the public site's actual URL; its local default is http://localhost:5173. Rebuild after changing that public website URL in production.

## Pages and operations

All six collections have table pages with search, sorting, pagination, view/edit links, refresh, and confirmed deletion. Create opens `/{collection}/new`, view opens `/{collection}/{id}`, and edit opens `/{collection}/{id}/edit`. Invalid collections and IDs show a 404 page.

Description inputs use Quill for Books, Podcasts, Tips & Tricks, News, and News Letter. Contact Us uses a plain textarea. Descriptions preserve rich HTML, sanitized by the backend and again on display. Content forms include title, image URL, YouTube URL, and publication date. Contacts include first/last name, message, email, phone, and creation date.

Create uses POST. **Save changes** uses PUT and sends all editable fields. **Save changed fields** uses PATCH and sends only fields edited on that page. Cancel returns to the collection or record. Successful saves open the record page. Dates are entered and displayed in the browser's local timezone and sent to the API as ISO strings. IDs are generated by the database. News Letter is a content collection; email subscription or delivery is outside this dashboard's scope.

The dashboard uses the public site's existing logo, footer logo, and crest, stored in `public/brand`. It shares the site's Syne/Plus Jakarta Sans typography, ink and amber palette, and strong action borders. Overview counts and latest records come from the API. Empty collections invite creation; failures offer retry. Navigation collapses on mobile, and tables scroll horizontally.

## Administrator access

`/login` is public. All CMS pages are checked on the server against the backend `/auth/me` endpoint and require an active admin session. Requests without a session cookie redirect to login. Forged, expired, disabled, and non-admin sessions cannot access CMS data. Successful login returns to the requested collection or the overview. Sign out revokes the database session and clears its cookie. Sessions expire after eight hours. The login form supports password visibility and shows login/server errors without exposing credentials.

Browser API requests pass through the same-origin `/api/backend` route handler, which forwards only known CMS/auth endpoints. This avoids cross-domain cookie requirements. Session cookies are HttpOnly and SameSite Strict. Mutating requests require a custom header and a matching request origin. The Express API also independently authenticates and authorizes every CMS operation. No password or session token is kept in localStorage or embedded in the browser bundle.

The proxy checks the browser Origin against the incoming dashboard Host and the platform's forwarded protocol, rather than Next's internal server URL. After this check, its server-to-server backend request carries the CSRF header and session cookie but omits the browser Origin. This prevents valid dashboard requests from being rejected by the backend's separate browser-origin allowlist. On Vercel, set `API_INTERNAL_URL=https://infulencers-backend.vercel.app` in the dashboard project and redeploy after changing it.

```powershell
npm run typecheck
npm run build
npm run test:proxy
npm start
```

Fonts are installed locally, so the build does not need Google Fonts. See `DESIGN.md` for design decisions.

After building, the proxy integration test starts the production dashboard with a mock backend that rejects forwarded Origin headers. It covers sign-in/session/sign-out forwarding, foreign-origin and missing-header rejection, upstream/transport 503 responses, and responsive logo preload behavior. Tests use synthetic credentials and do not connect to the production database.

Quill 2.0.3 currently has an HTML-export advisory (GHSA-v3m3-f69x-jf25) and no patched release. This integration sanitizes imported and exported editor HTML with DOMPurify, sanitizes again on the server, and sanitizes rendered rich content. The dependency audit still reports that upstream advisory.
